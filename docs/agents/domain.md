# Domain Docs

This repository uses a single-context domain-document layout.

Before exploring, read `CONTEXT.md` and any relevant ADRs under `docs/adr/` when they exist. Their absence is not an error: the domain-modeling workflow creates them lazily when terminology or durable architectural decisions are resolved.

Use terminology defined in `CONTEXT.md` consistently. Surface conflicts with existing ADRs explicitly rather than silently overriding them.
